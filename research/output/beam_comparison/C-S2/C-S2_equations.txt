  1. beta_1 (Stress block factor)
     f_c' <= 28 -> beta_1 = 0.85

  2. A_s,min (Minimum reinforcement)
     A_s,min1 = 0.25*sqrt(f_c')/f_y * b * d
              = 0.25*sqrt(28.0)/420.0 * 250.0 * 342.55 = 269.733 mm2
     A_s,min2 = 1.4/f_y * b * d
              = 1.4/420.0 * 250.0 * 342.55 = 285.458 mm2
     A_s,min  = max(269.733, 285.458) = 285.458 mm2

  3. A_s,max (Maximum reinforcement)
     A_s,bal = 0.85*f_c'*beta_1*(eps_cu/(eps_cu+eps_y))*d
             = 0.85*28.0*0.850*(0.003/(0.003+0.00210))*342.55
             = 4076.345 mm2
     A_s,max = 0.75*A_s,bal = 0.75*4076.345 = 3057.259 mm2

  4. Effective depths
     d   = h - p - dt - dl/2 = 400.0 - 40.0 - 9.5 - 15.9/2 = 342.55 mm
     d'  = p + dt + dl/2 = 40.0 + 9.5 + 15.9/2 = 57.45 mm

  5. Neutral axis & stress block
     a   = solved from M_u/phi = 0.85*f_c'*b*a*(d-a/2)
     a   = 42.05 mm
     c   = a/beta_1 = 42.05/0.850 = 49.47 mm

  6. Concrete compression force
     C_c = 0.85*f_c'*b*a = 0.85*28.0*250.0*42.05 = 250181.20 N

  7. Required tension reinforcement
     A_s = C_c / f_y = 250181.20 / 420.0 = 595.670 mm2

  8. Nominal & design moment
     M_n   = C_c*(d - a/2) = 250181.20*(342.55 - 42.05/2) = 80439853.68 N-mm
     phiM_n  = phi*M_n = 0.90*80439853.68 = 72395868.31 N-mm
            = 72.396 kN-m

  9. Demand-Capacity Ratio (DCR)
     DCR  = M_u / phiM_n = 56.25 / 72.396 = 0.777
     -> DCR <= 1.0, section is ADEQUATE
