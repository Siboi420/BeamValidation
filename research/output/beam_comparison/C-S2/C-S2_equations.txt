  1. beta_1 (Stress block factor)
     f_c' <= 28 -> beta_1 = 0.85

  2. A_s,min (Minimum reinforcement)
     A_s,min1 = 0.25*sqrt(f_c')/f_y * b * d
              = 0.25*sqrt(28.0)/420.0 * 250.0 * 342.00 = 269.300 mm2
     A_s,min2 = 1.4/f_y * b * d
              = 1.4/420.0 * 250.0 * 342.00 = 285.000 mm2
     A_s,min  = max(269.300, 285.000) = 285.000 mm2

  3. A_s,max (Maximum reinforcement)
     A_s,bal = 0.85*f_c'*beta_1*(eps_cu/(eps_cu+eps_y))*d
             = 0.85*28.0*0.850*(0.003/(0.003+0.00210))*342.00
             = 4069.800 mm2
     A_s,max = 0.75*A_s,bal = 0.75*4069.800 = 3052.350 mm2

  4. Effective depths
     d   = h - p - dt - dl/2 = 400.0 - 40.0 - 10.0 - 16.0/2 = 342.00 mm
     d'  = p + dt + dl/2 = 40.0 + 10.0 + 16.0/2 = 58.00 mm

  5. Neutral axis & stress block
     a   = solved from M_u/phi = 0.85*f_c'*b*a*(d-a/2)
     a   = 42.58 mm
     c   = a/beta_1 = 42.58/0.850 = 50.09 mm

  6. Concrete compression force
     C_c = 0.85*f_c'*b*a = 0.85*28.0*250.0*42.58 = 253338.03 N

  7. Required tension reinforcement
     A_s = C_c / f_y = 253338.03 / 420.0 = 603.186 mm2

  8. Nominal & design moment
     M_n   = C_c*(d - a/2) = 253338.03*(342.00 - 42.58/2) = 81248316.19 N-mm
     phiM_n  = 0.9*M_n = 0.9*81248316.19 = 73123484.57 N-mm
            = 73.123 kN-m

  9. Demand-Capacity Ratio (DCR)
     DCR  = M_u / phiM_n = 56.25 / 73.123 = 0.769
     -> DCR <= 1.0, section is ADEQUATE
