  1. beta_1 (Stress block factor)
     f_c' <= 28 -> beta_1 = 0.85

  2. A_s,min (Minimum reinforcement)
     A_s,min1 = 0.25*sqrt(f_c')/f_y * b * d
              = 0.25*sqrt(28.0)/420.0 * 300.0 * 639.40 = 604.176 mm2
     A_s,min2 = 1.4/f_y * b * d
              = 1.4/420.0 * 300.0 * 639.40 = 639.400 mm2
     A_s,min  = max(604.176, 639.400) = 639.400 mm2

  3. A_s,max (Maximum reinforcement)
     A_s,bal = 0.85*f_c'*beta_1*(eps_cu/(eps_cu+eps_y))*d
             = 0.85*28.0*0.850*(0.003/(0.003+0.00210))*639.40
             = 7608.860 mm2
     A_s,max = 0.75*A_s,bal = 0.75*7608.860 = 5706.645 mm2

  4. Effective depths
     d   = h - p - dt - dl/2 = 700.0 - 40.0 - 9.5 - 22.2/2 = 639.40 mm
     d'  = p + dt + dl/2 = 40.0 + 9.5 + 22.2/2 = 60.60 mm

  5. Neutral axis & stress block
     a   = solved from M_u/phi = 0.85*f_c'*b*a*(d-a/2)
     a   = 113.85 mm
     c   = a/beta_1 = 113.85/0.850 = 133.94 mm

  6. Concrete compression force
     C_c = 0.85*f_c'*b*a = 0.85*28.0*300.0*113.85 = 812858.82 N

  7. Required tension reinforcement
     A_s = C_c / f_y = 812858.82 / 420.0 = 1935.378 mm2

  8. Nominal & design moment
     M_n   = C_c*(d - a/2) = 812858.82*(639.40 - 113.85/2) = 473471661.63 N-mm
     phiM_n  = phi*M_n = 0.90*473471661.63 = 426124495.46 N-mm
            = 426.124 kN-m

  9. Demand-Capacity Ratio (DCR)
     DCR  = M_u / phiM_n = 360.00 / 426.124 = 0.845
     -> DCR <= 1.0, section is ADEQUATE

        = 172.553 kN

  Shear reinforcement required?     Yes

  Required V_s = V_u/phi - V_c = 240.00/0.75 - 172.553 = 147.447 kN
  Required spacing, s_req = A_v*f_yt*d / V_s

  Shear DCR = V_u / phiV_n = 240.00 / 241.387 = 0.994
