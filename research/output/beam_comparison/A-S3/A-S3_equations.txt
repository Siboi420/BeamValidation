  1. beta_1 (Stress block factor)
     f_c' <= 28 -> beta_1 = 0.85

  2. A_s,min (Minimum reinforcement)
     A_s,min1 = 0.25*sqrt(f_c')/f_y * b * d
              = 0.25*sqrt(28.0)/420.0 * 300.0 * 640.00 = 604.743 mm2
     A_s,min2 = 1.4/f_y * b * d
              = 1.4/420.0 * 300.0 * 640.00 = 640.000 mm2
     A_s,min  = max(604.743, 640.000) = 640.000 mm2

  3. A_s,max (Maximum reinforcement)
     A_s,bal = 0.85*f_c'*beta_1*(eps_cu/(eps_cu+eps_y))*d
             = 0.85*28.0*0.850*(0.003/(0.003+0.00210))*640.00
             = 7616.000 mm2
     A_s,max = 0.75*A_s,bal = 0.75*7616.000 = 5712.000 mm2

  4. Effective depths
     d   = h - p - dt - dl/2 = 700.0 - 40.0 - 10.0 - 20.0/2 = 640.00 mm
     d'  = p + dt + dl/2 = 40.0 + 10.0 + 20.0/2 = 60.00 mm

  5. Neutral axis & stress block
     a   = solved from M_u/phi = 0.85*f_c'*b*a*(d-a/2)
     a   = 92.40 mm
     c   = a/beta_1 = 92.40/0.850 = 108.71 mm

  6. Concrete compression force
     C_c = 0.85*f_c'*b*a = 0.85*28.0*300.0*92.40 = 659734.46 N

  7. Required tension reinforcement
     A_s = C_c / f_y = 659734.46 / 420.0 = 1570.796 mm2

  8. Nominal & design moment
     M_n   = C_c*(d - a/2) = 659734.46*(640.00 - 92.40/2) = 391750391.99 N-mm
     phiM_n  = 0.9*M_n = 0.9*391750391.99 = 352575352.79 N-mm
            = 352.575 kN-m

  9. Demand-Capacity Ratio (DCR)
     DCR  = M_u / phiM_n = 292.50 / 352.575 = 0.830
     -> DCR <= 1.0, section is ADEQUATE
