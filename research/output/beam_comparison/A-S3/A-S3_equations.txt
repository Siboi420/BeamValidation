  1. beta_1 (Stress block factor)
     f_c' <= 28 -> beta_1 = 0.85

  2. A_s,min (Minimum reinforcement)
     A_s,min1 = 0.25*sqrt(f_c')/f_y * b * d
              = 0.25*sqrt(28.0)/420.0 * 300.0 * 636.20 = 601.152 mm2
     A_s,min2 = 1.4/f_y * b * d
              = 1.4/420.0 * 300.0 * 636.20 = 636.200 mm2
     A_s,min  = max(601.152, 636.200) = 636.200 mm2

  3. A_s,max (Maximum reinforcement)
     A_s,bal = 0.85*f_c'*beta_1*(eps_cu/(eps_cu+eps_y))*d
             = 0.85*28.0*0.850*(0.003/(0.003+0.00210))*636.20
             = 7570.780 mm2
     A_s,max = 0.75*A_s,bal = 0.75*7570.780 = 5678.085 mm2

  4. Effective depths
     d   = h - p - dt - dl/2 = 700.0 - 40.0 - 12.7 - 22.2/2 = 636.20 mm
     d'  = p + dt + dl/2 = 40.0 + 12.7 + 22.2/2 = 63.80 mm

  5. Neutral axis & stress block
     a   = solved from M_u/phi = 0.85*f_c'*b*a*(d-a/2)
     a   = 91.08 mm
     c   = a/beta_1 = 91.08/0.850 = 107.15 mm

  6. Concrete compression force
     C_c = 0.85*f_c'*b*a = 0.85*28.0*300.0*91.08 = 650287.06 N

  7. Required tension reinforcement
     A_s = C_c / f_y = 650287.06 / 420.0 = 1548.303 mm2

  8. Nominal & design moment
     M_n   = C_c*(d - a/2) = 650287.06*(636.20 - 91.08/2) = 384099654.06 N-mm
     phiM_n  = phi*M_n = 0.90*384099654.06 = 345689688.65 N-mm
            = 345.690 kN-m

  9. Demand-Capacity Ratio (DCR)
     DCR  = M_u / phiM_n = 292.50 / 345.690 = 0.846
     -> DCR <= 1.0, section is ADEQUATE
